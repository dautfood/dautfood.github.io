# ВкусДинара — проект сайта

Сайт — https://vkusdinara.github.io/menu/

Репозиторий — https://github.com/vkusdinara/menu

PDF-меню — https://vkusdinara.github.io/menu/downloads/vkus-dinara-menu.pdf

Как открыть в VS Code:

1. Распакуйте ZIP-архив.
2. Откройте VS Code.
3. File → Open Folder.
4. Выберите папку `vkus-dinara-vscode-project`.
5. Откройте `index.html`.

Для удобного просмотра сайта:
- установите расширение Live Server;
- нажмите правой кнопкой по `index.html`;
- выберите `Open with Live Server`.

Структура проекта:

vkus-dinara-vscode-project-photos-v5/
├── index.html      — структура и содержимое сайта
├── style.css       — дизайн
├── script.js       — фильтры и поиск

└── README.md       — эта инструкция
